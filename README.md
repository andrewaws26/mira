# Mira

Conversational telescope control for the Celestron NexStar 130SLT.

Mira is named for the Spanish word "look" and the variable star Mira in Cetus. It lets you point the telescope at any patch of sky, say "Mira, show me Jupiter," and have the system plate-solve the current pointing then slew to the target. No traditional star alignment required.
